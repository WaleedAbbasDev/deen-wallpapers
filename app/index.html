Auto lock screen

This makes your iPhone switch to a new reminder automatically, using Apple's free Shortcuts app. You only set it up once.

Before you start

Your lock screen must be a normal Photo wallpaper (not "Photo Shuffle"). Save any reminder with Save to Photos, then long-press the lock screen → + → Photos → pick it.

Step 1 · Make the shortcut

  1. Open Shortcuts → tap +. Name it Deen Wallpaper.
  2. Add the action Random Number. Set Minimum 1 and Maximum 200.
  3. Add the action Text and type this address. Where it says NUMBER, delete that word and insert the blue Random Number variable instead:
  4. Add Get Contents of URL (it will use the Text automatically).
  5. Add Set Wallpaper Photo (called Set Wallpaper on older iOS). Tap it, choose your current wallpaper, and turn off "Show Preview". If you see "Crop to Subject", turn that off too.
  6. Tap ▶︎ once to test. When it asks to allow access to github.io, choose Always Allow.

Step 2 · Make it run by itself

  1. In Shortcuts, go to the Automation tab → +.
  2. Time of Day: pick a time (for example Fajr), Daily, choose Run Immediately, then pick Deen Wallpaper. Add a few of these through the day.
  3. App (recommended): choose Instagram, TikTok, YouTube, etc. → Is Opened → Run Immediately → Deen Wallpaper. Every time you open a distraction, a fresh reminder waits on your lock screen.
  4. Optional: Charger → Is Connected, so you wake up to a new reminder.

Add this app to your Home Screen

In Safari tap Share → Add to Home Screen. It opens full-screen like a normal app.

About the reminders

New wallpapers are made automatically every few hours, so the collection keeps changing.

The Holy Quran

English translation by Saheeh International. Chosen ayahs about remembrance, this life and the Hereafter, plus other short ayahs picked from the whole Quran each time.

Sahih Hadith

Only from Sahih al-Bukhari and Sahih Muslim, with their hadith numbers so you can look them up.

Hazrat Ali (RA)

Sayings from Nahj al-Balagha. Saying numbers can differ by one or two between printed editions.

Allama Iqbal & Maulana Rumi

Iqbal's verses with the original Urdu (in Roman letters) and an English meaning; Rumi from the Masnavi and Fihi Ma Fihi.

The hadith, Ali, Iqbal and Rumi texts are English renderings of the meaning. Check any reminder in a trusted book or with a scholar if you are unsure.
